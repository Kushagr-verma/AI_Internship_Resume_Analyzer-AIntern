# AIntern

## Overview
AItern is an AI-based internship recommendation application that has been created using Flask.

The system enables students to upload their resume, parse the content from PDF, and make recommendations for internships using job datasets that match.
---

## Features
 Resume Upload
 PDF Text Extraction
 Internship Matching
 Responsive User Interface
 Flask Backend
